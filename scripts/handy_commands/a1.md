# 🧠 Quick Memory Guide — How to View Contents of a `vcf.gz`

## 🔹 Basic viewing (header + first lines)
- View with scrolling:
  ```bash
  zless file.vcf.gz
  ```

- Print raw first lines:
  ```bash
  zcat file.vcf.gz | head
  ```

## 🔹 Data lines only
- Skip header
    ```bash
    zcat file.vcf.gz | grep -v '^##' | head

## 🔹 Proper VCF-aware viewing (recommended)
- Header only:
    ```bash
    bcftools view -h file.vcf.gz
    ```
- First 20 variant rows (no header):
    ```bash
    bcftools view -H file.vcf.gz | head -n 20
    ```
- Header + first variants:
    ```bash
    bcftools view file.vcf.gz | head -n 40
    ```

## 🔹 Focused queries
- Show `CHROM`, `POS`, `ID`, `REF`, `ALT`, `QUAL`  
  ```bash
  bcftools query \
    -f '%CHROM\t%POS\t%ID\t%REF\t%ALT\t%QUAL\n' \
    file.vcf.gz | head
  ```
- Region-based extract (requires `.tbi` or `.csi`)  
  ```bash
  bcftools view -r 1:100000-200000 file.vcf.gz | less
  ```

## 🔹 Search for one variant (ID)
- With grep
    ```bash
    zgrep 'rs966221' file.vcf.gz
    ```
- With bcftools (VCF-aware)
    ```bash
    bcftools view -H -i 'ID="rs966221"' file.vcf.gz
    ```
