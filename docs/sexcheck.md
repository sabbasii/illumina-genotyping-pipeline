# Sex-check QC — What, Why, How

This document explains why we run a sex-check, how PLINK2 infers sex from variants, the thresholds we use (XF and YRATE), and how to run + interpret the reports generated by `scripts/export_sexcheck_reports.sh`.

Everything here uses the same paths/variables defined in `scripts/00_config.sh`.

---

## Why do a sex-check?

When genotyping arrays are processed, the declared sex in the SampleSheet can sometimes be wrong (typo, swap, plate error).  
A sex-check compares:

- **Recorded sex** (from SampleSheet → `metadata/cohort.sex.psam`)  
- **Variant-inferred sex** (from chrX/chrY data via PLINK2)

Catching mismatches early prevents downstream problems (PCA, association tests, imputation QC), and helps identify swaps or aneuploidies.

---

## What metrics does PLINK2 use?

PLINK2’s `--check-sex` uses two key features (we’ve already split PARs):

- **X-chromosome inbreeding coefficient (XF, often labeled F)**  
  - Computed on non-PAR chrX markers.  
  - Females have two X copies → more heterozygosity → XF ~ 0.0.  
  - Males are hemizygous on non-PAR X → essentially no heterozygosity → XF ~ 1.0.  
  - Borderline values (0.2–0.8) can reflect mosaicism, aneuploidy, or noisy data.

- **chrY call rate (YRATE)**  
  - Proportion of valid genotype calls on chrY markers.  
  - Females: YRATE ~ 0 (no chrY).  
  - Males: YRATE > 0 (array-dependent; even small >0 can be informative).

ℹ️ We split X PARs correctly by using `--split-par b37` for GRCh37 in the chrX pfile creation (see `scripts/qc_vcf.sh`). Do **not** pass `--chr-set` with `--split-par`.

---

## Thresholds used in this repo

We use practical defaults tuned for arrays:

- `min-male-xf = 0.8` (if XF ≥ 0.8, genotype evidence is strongly male)  
- `max-female-yrate = 0.02` (if a “female” has YRATE > 0.02, that’s suspicious; relax to 0.05 if your panel has many weak Y probes)

These are passed to PLINK2 as:

```bash
--check-sex 'min-male-xf=0.8' 'max-female-yrate=0.02'
```

If many females are flagged only by tiny YRATE (>0.02), try 0.05.  
If you want to be stricter for males, try `min-male-xf=0.85`.

## What files does the pipeline create?

After you run `scripts/qc_vcf.sh`, you should have:

- Permanent chrX pfiles (so you can recheck anytime):  
  ```
  $PLINK_DIR/chrX.{pgen,pvar,psam}
  ```
  e.g. `output/genotype_run1/qc/plink/chrX.pgen`

- PLINK2 QC outputs:  
  ```
  $PLINK_DIR/cohort.chrX.{afreq,smiss,vmiss,hardy.x}.gz
  ```

- Then `scripts/export_sexcheck_reports.sh` writes tidy reports to:  
  ```
  $OUT_DIR/qc/sexcheck_reports/
  ```

**Contents:**

- `sexcheck.slim.tsv` — IID, STATUS, PEDSEX, SNPSEX, XF, YRATE  
- `sexcheck.summary.txt` — counts per STATUS (OK / PROBLEM)  
- `sexcheck.problems.tsv` — only rows where STATUS=PROBLEM  
- `sexcheck.problems_with_recorded.tsv` — same as above + recorded sex joined in  
- `sexcheck.borderline.tsv` — samples with borderline XF ([0.10–0.30] or [0.80–0.85))  
- `xf_hist.tsv` / `xf_hist_ascii.txt` — numeric and ASCII histogram of XF  
- `yrate_hist.tsv` / `yrate_hist_ascii.txt` — numeric and ASCII histogram of YRATE (0.00–0.10, step 0.01)

Paths are consistent with:

- `OUT_DIR = output/<RUN>`  
- `PLINK_DIR = $OUT_DIR/qc/plink`  
- `PSAM_SEX = metadata/cohort.sex.psam`  
- `SEXMAP_PATH = metadata/sexmap.txt`  

All are set in `scripts/00_config.sh`.

## How to run

Make sure you’ve run QC (creates chrX pfiles and PLINK stats):

```bash
# from repo root
source scripts/00_config.sh
bash scripts/qc_vcf.sh
```

(Re)run sex-check manually (optional one-liner, uses permanent chrX pfile):

```bash
plink2 --pfile "$PLINK_DIR/chrX"   --threads "${THREADS:-16}"   --check-sex 'min-male-xf=0.8' 'max-female-yrate=0.02'   --out "$PLINK_DIR/cohort.sexcheck"
```

Export tidy reports (this doc’s main script):

```bash
bash scripts/export_sexcheck_reports.sh
# reports at: $OUT_DIR/qc/sexcheck_reports/
```

---

## Checklist of what to do next

### 1) Quick summary & spot issues
```bash
OUT="$OUT_DIR/qc/sexcheck_reports"
cat "$OUT/sexcheck.summary.txt"
sed -n '1,20p' "$OUT/sexcheck.problems_with_recorded.tsv" | column -t
```

### 2) Inspect distributions
```bash
column -t "$OUT/xf_hist.tsv" | sed -n '1,20p'
sed -n '1,20p' "$OUT/xf_hist_ascii.txt"
column -t "$OUT/yrate_hist.tsv" | sed -n '1,20p'
sed -n '1,20p' "$OUT/yrate_hist_ascii.txt"
```

Healthy cohorts:  
- mode near XF ≈ 0.0 (females)  
- mode near XF ≈ 0.9–1.0 (males)  
- YRATE ≈ 0 for females

### 3) Decide actions for PROBLEM rows
```bash
less -S "$OUT/sexcheck.problems_with_recorded.tsv"
```

Guidance:  
- PEDSEX=2 (female) but XF ~0.9 + YRATE >0 → likely male  
- PEDSEX=1 (male) but XF ~0.0 + YRATE ~0 → likely female  
- If many females flagged only for tiny YRATE (~0.02–0.05), relax Y threshold

### 4) (Optional) Re-run with relaxed Y gate
```bash
plink2 --pfile "$PLINK_DIR/chrX"   --check-sex 'min-male-xf=0.8' 'max-female-yrate=0.05'   --out "$PLINK_DIR/cohort.sexcheck_relaxed"

awk 'NR>1{c[$6]++}END{for(k in c)print k,c[k]}' "$PLINK_DIR/cohort.sexcheck.sexcheck"
awk 'NR>1{c[$6]++}END{for(k in c)print k,c[k]}' "$PLINK_DIR/cohort.sexcheck_relaxed.sexcheck"
```

### 5) Apply targeted corrections
```bash
OVR="$QC_DIR/tmp/sex_overrides.txt"
printf "%s	%s	%s
" "IID_TO_FIX" "IID_TO_FIX" "2" >> "$OVR"

plink2 --pfile "$PLINK_DIR/chrX" --update-sex "$OVR"        --make-pgen --out "$PLINK_DIR/chrX_fixed"

plink2 --pfile "$PLINK_DIR/chrX_fixed"   --check-sex 'min-male-xf=0.8' 'max-female-yrate=0.02'   --out "$PLINK_DIR/cohort.sexcheck_fixed"
```

If fixes look good:  
- update SampleSheet sex and rebuild PSAM, **or**  
- keep override file in repo (e.g., `metadata/sex_overrides.txt`) and apply automatically.

### 6) Log the outcome
```bash
DOC="docs/QC_issues.md"
{
  echo "## $(date +%F) Sex-check review ($RUN)"
  echo
  echo "- Summary:"
  cat "$OUT/sexcheck.summary.txt"
  echo
  echo "- Problem samples (top 10):"
  sed -n '1,11p' "$OUT/sexcheck.problems_with_recorded.tsv"
  echo
} >> "$DOC"
```

### 7) Commit artifacts & docs
```bash
git add scripts/export_sexcheck_reports.sh docs/sexcheck.md docs/QC_issues.md
git add "$OUT_DIR/qc/sexcheck_reports/"*.{tsv,txt} 2>/dev/null || true
git commit -m "QC: sex-check reports for $RUN; docs + exporter script"
```

### 8) Continue QC
Use autosome pfile (`$OUT_DIR/qc/plink_tmp/autosomes` or make a permanent one) to:

- filter by missingness/HWE/MAF  
- run PCA, relatedness (KING), het checks
