# Output Files

This document describes the files generated by the pipeline.  
They are divided into sub categories:

1. **Conversion Outputs** – created by `03_gtc_to_vcf_bcftools.sh`  
2. **QC Outputs** – created by `scripts/qc_vcf.sh`  

All paths are relative to `output/<RUN>/`.

---

## 1. Conversion Outputs: `output/<RUN>/vcf/`

When you run `03_gtc_to_vcf_bcftools.sh`, the following files are generated:

### 1.1 **cohort.gtc.<REF_BUILD>.raw.bcf**
- **What it is:** Unsorted BCF produced directly by the `bcftools +gtc2vcf` plugin.  
- **Purpose:** Captures raw genotypes straight from GTCs before coordinate sorting or normalization.  
- **Index:** `.raw.bcf.csi`.

---

### 1.2 **cohort.gtc.<REF_BUILD>.norm.bcf**
- **What it is**: Sorted and normalized BCF.  
- **Steps applied**:  
  - Variants sorted by genomic coordinates.  
  - Left-aligned against reference (`--fasta-ref`).  
  - Multiallelic variants split.  
  - REF mismatches dropped.  
- **Purpose**: Clean canonical BCF used as the main working file.  
- **Index**: `.norm.bcf.csi`.

---

### 1.3 **cohort.gtc.<REF_BUILD>.norm.vcf.gz**
- **What it is**: VCF equivalent of the normalized BCF, compressed with bgzip.  
- **Purpose**: Human-readable and compatible with downstream tools (e.g., PLINK, imputation, sharing).  
- **Index**: `.norm.vcf.gz.tbi`.

---

### 1.4 **tmp.tags.bcf**
- **What it is**: Copy of the normalized BCF with extra INFO fields filled by `bcftools +fill-tags`.  
- **Tags include**: AC (allele count), AN (allele number), AF (allele frequency), etc.  
- **Purpose**: Adds population/genotype summary annotations useful for QC.  
- **Index**: `.tags.bcf.csi`.  
- **Note**: Named `tmp` because it’s written into the `$TMP_DIR`, but kept for reuse.  

---

### 1.5 **tmp/**
- Temporary working directory used by `bcftools sort`.  
- Can be safely deleted after successful run, but useful if re-running partially.  

---

### 1.6 **cohort.gtc.<REF_BUILD>.norm.primary.vcf.gz** *(optional)*
- **What it is:** VCF subset to primary chromosomes only (`1..22, X, Y, MT`).  
- **Purpose:** Simplifies downstream GWAS/QC that ignores unplaced scaffolds (e.g., `GL0002xx`).  
- **How generated:**  
  ```bash
  MAKE_PRIMARY=1 bash scripts/qc_vcf.sh
  ```
  File is bgzipped and indexed (`.tbi`).
  Index: .norm.primary.vcf.gz.tbi.

---

## 2. QC Outputs: output/<RUN>/qc/

When you run `scripts/qc_vcf.sh`, the following quality control files are generated:

### 2.1 `header.txt`
- **What it is:** Full VCF header (`##` metadata + `#CHROM` line).
- **Purpose:** Snapshot of metadata, version info, and sample IDs.

From the project root & inspect the header:
```bash
cd output/<RUN>/qc          # Replace <RUN> with genotype_run1
less header.txt             # open full file, scroll with ↑/↓, search with /, quit with q
head -n 20 header.txt       # show first 20 lines
grep '^##' header.txt       # show metadata lines only
grep '^#CHROM' header.txt   # show column header line
```

### 2.2 `contigs.list`
- **What it is:** List of contig IDs extracted from the VCF header.
- **Purpose:** Confirms contig naming matches the reference (e.g., 1..22, X, Y, MT).

From the project root & inspect contigs:
```bash
less contigs.list        # scroll through all contigs, quit with q
head contigs.list        # see the first few (e.g., 1..10)
tail contigs.list        # see the last few (e.g., MT, X, Y)
wc -l contigs.list       # count total number of contigs
```

### 2.3 `fasta_contigs.list`
- **What it is:** Contig IDs from the reference FASTA index (reference.fa.fai).
- **Purpose:** Used to cross-check with contigs.list.

### 2.4 `contigs.diff`
- **What it is:** Differences between contigs.list and fasta_contigs.list.
- **Purpose:** Empty file = perfect match. Non-empty file = potential mismatch between manifest and reference.

### 2.5 `samples.list`
- **What it is:** All sample IDs from the VCF header.
- **Purpose:** Confirms every .gtc processed appears in the VC

### 2.6 `samples.count`
- **What it is:** Number of samples (integer).
- **Purpose:** Should equal the count of .gtc files processed.

### 2.7 `variants.count`
- **What it is:** Total number of variant records in the VCF.
- **Purpose:** Should match expected number of SNPs (~700–750k for GSA v3).

### 2.8 `variants_by_contig.txt`
- **What it is:** Variant counts per chromosome.
- **Purpose:** Sanity check coverage across autosomes, sex chromosomes, MT, and scaffolds.

### 2.9 `bcftools.stats.txt`
- **What it is:** Summary QC report from bcftools stats.
- **Purpose:** Provides metrics such as Ti/Tv ratio, singleton rate, depth distribution, multiallelic proportion.

### 2.10 `vcfstats_plots/`
- **What it is:** Plots generated by plot-vcfstats.
- **Purpose:** Visual representation of bcftools.stats.txt.

### 2.11 `refcheck.log`
- **What it is:** Log from bcftools norm -c ws check.
- **Purpose:** Captures any warnings about REF/ALT mismatches vs reference FASTA.

### 2.12 `ref_mismatch.summary`
- **What it is:** Grep-filtered summary of REF allele mismatches.
- **Purpose:** Should be empty if manifest and reference are consistent.

### 2.13 `af.tsv.gz`
- **What it is:** Table of allele frequencies (`CHROM, POS, ID, AF`) extracted with `bcftools +fill-tags`.
- **Purpose:** Snapshot of allele frequency distribution across the cohort.

### 2.14 `primary_contigs.list`
- **What it is:** Directory of PLINK2 QC outputs.
- **Files include:**
      cohort.imiss → per-sample missingness.
      cohort.lmiss → per-variant missingness.
      cohort.afreq → allele frequency spectrum.
      cohort.hardy → Hardy–Weinberg equilibrium test.
- **Purpose:** Provides GWAS-style QC metrics widely used in downstream analysis.

---

# Summary
### Conversion outputs (vcf/) give you raw, normalized, and optional primary-only VCF/BCF files.

### QC outputs (qc/) provide validation, sanity checks, allele frequencies, and GWAS-style QC metrics.

### Together, these files form a reproducible record of both data generation and data quality.
